파이썬 모듈 locale

다음의 코드는 파이썬 버전을 확인한 후, 파이썬의 지역 설정 및 인코딩 방법을 정할 때 쓸 수 있는 이름을 보여준다.

# 파이썬 버전 확인
import sys
sys.version

# 지역 이름
import locale
locale.locale_alias

# 인코딩 이름
locale.locale_encoding_alias
